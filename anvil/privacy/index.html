Anvil — Privacy Policy

Last updated: 2026-10-19

Anvil is a personal, single-user automation agent operated by Kyle Yi (younatics). It is not offered as a service to the public.

What data it accesses

When the operator connects a Google account, Anvil may read Gmail messages and Google Calendar events of that account, using only the scopes the operator approves (currently read-only access to Gmail and Calendar).

How data is used and stored

Data is used solely to assist the operator (summaries, reminders, scheduling). OAuth tokens and any cached data are stored on the operator's own computer. No data is sent to third parties, sold, or used for advertising. Google user data is never shared with or transferred to any other party.

Limited Use

Anvil's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access deletes the stored tokens' usefulness immediately; cached data can be deleted on request to the operator.
